# College Health Risk Guide

A responsive React and Tailwind CSS website for a KIN 619 Public Health Practicum project at Kansas State University.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Vercel

Vercel can deploy this project with the default Vite settings:

- Build command: `npm run build`
- Output directory: `dist`
